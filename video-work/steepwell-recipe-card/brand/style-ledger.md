# Style ledger

One row per shipped video — the memory that keeps a brand's videos from repeating
themselves. Append one row at QC when a video ships; the style pick at stage 2 reads the
recent rows to rotate variant axes and avoid repeating the last look.

**Column definitions:**

- **Date** — ship date (`YYYY-MM-DD`).
- **Video** — the piece's slug (its `video-work/<slug>/` folder name).
- **Tier** — importance tier you produced it at (flagship / routine / test). Flagship
  pieces earn the A/B styleframe gate and more iteration; tests are throwaways.
- **Style** — which archetype from the roster (Launch Film, Mechanism Explainer, Kinetic
  Essay, Announcement Card, Content Hero).
- **Audio** — silent / bed / VO / music (matches the render's actual audio mode).
- **Camera** — the camera moves used (push-in, pull-back reveal, drift, target-zoom), or
  `none` for a held-camera piece.
- **Hero techniques** — the signature moves and notable craft in this piece; what made it
  work.
- **New capabilities tried** — anything used for the first time here (a new transition, a
  new audio path, a first camera move). This column is how the next piece knows what is
  already proven and what is still untried.
- **Destinations** — where it shipped (the rows from your delivery matrix).
- **Perf note** — the QC or performance read after it went out; a one-line gut check, not
  a report.
