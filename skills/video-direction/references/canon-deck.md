# Canon deck — reference video teardowns

Frame-level breakdowns of best-in-class videos, each mapped to the style archetype it
anchors. This is the taste standard the process compares against.

- The **Look critic** (after styleframes) compares your frame side by side against the
  canon of the style the piece anchors to — same archetype, same register — and against
  your brand constants. A frame that drifts off the canon is caught here.
- The **Styleframes stage** presents your candidate frames beside the canon reference
  frame the chosen style points at, so the A/B pick is a comparison against a known-good
  standard, not a guess.

Each teardown analyzes a PUBLIC video — the source link is live, watch it — so the frame
notes and the source stay. What generalizes is the craft, not the brand: read these for
the *move* (how the camera narrates, how one accent carries meaning), then apply it in
your own world, type, and accent.

**Extend it:** when you find a video your brand should learn from, add a teardown. Watch
it, break it down frame by frame, name which archetype it anchors, and pull any new
transferable rule into the list at the bottom. Three archetypes have a canon entry today;
the other two (Kinetic Essay, Content Hero) are marked `canon: none yet` in
`style-archetypes.md` and are waiting for the right teardown.

## 1. Claude Code in-app browser launch — anchors **Launch Film**

Source: x.com/ClaudeDevs/status/2075635283211772279 · 47s · silent

- **Arc:** cold open punched in HARD on the prompt composer (black frame, just the input
  bar + context chips, prompt typing, mascot beside it) → one pull-back reveals the whole
  app → settles into a persistent split pane → punch-ins on payoff moments → kinetic-type
  outro ("Browse." → "Browse. Build. Ship.") → logo.
- **Split pane held for the whole middle:** agent conversation dark left (prompt bubble,
  status lines, findings table, tool-call list, inline diff), live browser light right.
  Dark/light does the cause/effect labeling without captions.
- **Camera IS the narration:** zoom out = orientation, zoom in = the point being made now
  (tool calls, a code diff, an action button, a PR chip). One move per beat, hold,
  release. No VO anywhere.
- **Exterior:** floating rounded window on a warm textured field; product window never
  fullscreen.
- **Mascot:** desk-toy scale on the UI, idle only; leads the outro.

Why it anchors Launch Film: the full narrative arc (cold-open hook → the thing revealed →
proof beats → wordmark resolve) carried by an eased camera and a scored-length runtime,
silent here but built to carry mood. This is the flagship register.

## 2. Vaults feature clip — anchors **Mechanism Explainer**

Source: x.com/ClaudeDevs/status/2065080009203892302 · 18s · silent

- **Register:** the structural opposite of the launch film. One mechanism, two scenes,
  hard cut, ZERO camera movement. Works because motion lives in the content and the frame
  holds two panels, never one window.
- **World inverted:** cream/paper background, dark UI cards floating on it — the only dark
  things in frame. Hierarchy purely from world/card contrast.
- **Mascot as static header lockup:** mark left of the serif title "Vaults," top-left,
  logo position, no animation. (A third mascot mode alongside the choreographed actor and
  the desk-toy perch.)
- **Caption-as-narrator:** ONE gray sentence under the title per beat; three sentences
  total = the entire script. Setup ("Register a key, an env var name, and the hosts it can
  reach") → constraint ("The sandbox only holds a placeholder") → payoff ("The real key is
  substituted at the network boundary").
- **Scene 1 (0–8s):** config-file card static left (syntax highlighted, the key term in an
  accent pill), terminal right — the command TYPES character by character, the JSON
  response prints at once. Typing is the only motion.
- **Scene 2 (8–18s):** animated diagram — entity cards, a dashed "network boundary"
  divider, a connection line draws across, a token chip TRAVELS the line and flips
  gray→ACCENT at the boundary. The color flip at the crossing IS the explanation: the
  accent marks the exact semantic moment.
- **Ending:** it just stops. No logo outro — feature clips don't earn one.

Why it anchors Mechanism Explainer: step-by-step "here's the machine" with the story spine
carried by captions, panels holding a static camera because the motion is content-level
(typing, line-draws, a traveling chip). The archetype's held-camera exemption is this clip.

## 3. Build Day announcement card — anchors **Announcement Card**

Source: x.com/ClaudeDevs/status/2064453497005978031 · 14s · square 720×720 · silent

- **The whole frame is a static designed card; the mascot is the ONLY motion.** Logo
  lockup top-left → big serif title → one sans sub-line → bottom panel rising from the
  frame edge (breadcrumb header + syntax-highlighted code snippet with copy button).
- **The details ARE the code:** the event logistics (`city`, `date`, `finalists`,
  `credits`) formatted as a code object — instantly legible to builders, boring facts
  become brand texture.
- **The mascot performs the title verb.** The character pantomimes "Build Day": welding
  mask on (a prop), sparks, welds, mask off — then the punchline, a tiny ™ appears beside
  it. End-gag rewards the full watch and makes the loop replayable.
- **Zero camera, zero cuts, square-first, works silent.** Cheapest possible format; all
  craft lives in one character bit.

Why it anchors Announcement Card: one held frame landing a single fact, the hierarchy
check (not the story spine) governing it, one charm/character bit as the only motion, and
silent-legible by construction.

## Transferable rules extracted

Brand-agnostic; each pulled from the teardowns above. Apply them in your own world.

1. **Accent color changes state at the semantic moment** (gray placeholder → accent real
   value). Color = meaning, never decoration.
2. **Commands type, responses print.** Input is human-paced, output is instant.
3. **A traveling chip along a drawn line** explains a data flow better than any narration.
4. **One sentence per beat is a complete script** for a ≤20s piece — caption-as-narrator,
   three or four sentences carry the whole clip.
5. **Static camera is legitimate** when the frame is multi-panel and the motion is
   content-level (typing, line-draws, traveling chips).
6. **Serif title + mascot/mark lockup = a brand header** for explainer registers.
7. **Camera is narration.** Zoom out orients, zoom in makes the point being made now; one
   move per beat, hold, release. A move without a reason is noise.
8. **Dark/light cause-effect labeling.** Split the frame by value (dark cause left, light
   effect right) and the contrast does the labeling captions would otherwise do.
9. **An end-gag rewards the full watch.** A final beat that pays off the setup (a punchline
   stamp, a ™, a costume-off reveal) makes a short loop replayable instead of disposable.
10. **A mascot/performing element can carry the title verb.** When the brand has one, the
    performed action should correlate with the title taken literally, and emit a visible
    effect that carries the verb.
